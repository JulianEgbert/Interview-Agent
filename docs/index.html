Why it matters

Most practice tools grade answers. InterviewRoom practices the room.

The prototype joins a LiveKit room as a calm, probing interviewer. It presents an original challenge, asks for clarification, nudges the candidate through tradeoffs and tests, then wraps with concise feedback on the full interview process.

Experience

Designed for realistic technical practice

01

Realtime interviewer

The agent starts the session, gives one problem, asks one question at a time, and keeps the tone supportive without turning into a solution walkthrough.

02

Screen-share context

Candidates can share their editor or browser while narrating decisions. The prototype is transparent about what it can and cannot read from the screen today.

03

Process feedback

The scorecard focuses on communication, clarification, algorithmic reasoning, edge cases, testing, complexity, and readiness for the next interview.

Demo flow

One polished interview path for a hackathon demo

The current agent can pick from a local challenge catalog, greet the candidate, guide the conversation, and close with structured feedback when the candidate says they are finished.

  1. Join

    Start a new-grad coding interview in a LiveKit room.

  2. Share

    Use voice and optional screen sharing while solving.

  3. Reason

    Clarify assumptions, discuss tradeoffs, test edge cases.

  4. Improve

    Finish with a scorecard and focused practice recommendation.

uv sync
uv run python src/agent.py console
uv run pytest
