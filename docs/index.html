Why it matters

Most practice tools grade answers. InterviewRoom practices the room.

The prototype joins a LiveKit room as a calm, probing interviewer. It presents an original challenge, asks for clarification, nudges the candidate through tradeoffs and tests, inspects their local solution file when asked, then writes concise feedback on the full interview process.

Latest prototype

A local browser room connected to LiveKit Cloud

Browser interview room

A tiny Python web server creates a room token, dispatches the local LiveKit agent, and lets the candidate join from localhost:8765.

Inspectable coding workspace

Coding challenges generate a local solution.py. The web UI opens that file in VS Code, and the agent can inspect it or run local tests at natural checkpoints.

Written evaluation

At the end of the interview, the agent can write an evaluation.md report with score bars, test results, thinking-aloud feedback, strengths, improvement areas, and next steps.

Experience

Designed for realistic technical practice

01

Realtime interviewer

The agent starts the session, gives one problem, asks one question at a time, and keeps the tone supportive without turning into a solution walkthrough.

02

Workspace context

Candidates work in the generated local solution file while narrating decisions. The agent can read that file and run challenge tests without needing a visual sharing setup.

03

Process feedback

The scorecard focuses on communication, thinking aloud, clarification, algorithmic reasoning, edge cases, testing, complexity, and readiness for the next interview.

Demo flow

One polished interview path for a hackathon demo

The current agent can pick from a local challenge catalog, greet the candidate, guide the conversation, and close with structured feedback when the candidate says they are finished.

  1. Join

    Start a coding interview from the local browser room.

  2. Code

    Open the generated solution file in VS Code and think aloud.

  3. Reason

    Clarify assumptions, discuss tradeoffs, and test edge cases.

  4. Improve

    Finish with a markdown scorecard and focused practice plan.

Prototype

Run the local web interview room

The landing page is plain HTML and CSS for GitHub Pages. The working interview prototype is a Python app powered by uv, LiveKit Agents, LiveKit Cloud, and a local browser room. Run the agent and web app in separate terminals, then open the local page. 

cp .env.example .env.local
uv sync

# Terminal 1
uv run python src/agent.py dev

# Terminal 2
uv run python src/web_app.py

# Browser
open http://localhost:8765

# Checks
uv run pytest
